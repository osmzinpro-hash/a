 Hardware é a parte física do computador: objetos tangíveis, como circuitos integrados, placas, cabos, fontes de energia, memórias e impressoras.

Conceito básico: segundo Tanenbaum e Austin (2013), o hardware é formado pelos objetos tangíveis do computador, ou seja, tudo o que é físico e pode ser tocado: placas, chips, cabos, fontes de energia, memórias, teclado, monitor e impressora. Na animação aparecem o gabinete, o monitor, o teclado e o mouse, e as luzes verdes mostram os dados passando de uma peça para a outra.

Estrutura básica do computador

Todo computador é formado por quatro partes que trabalham juntas.

1. Memória principal

É como uma mesa de estudo: guarda o que o computador está usando agora.

2. Processador

É o “cérebro”: segue as instruções dos programas e faz todas as contas.

3. Entrada e saída

São as “portas” do computador: por elas os dados entram e saem.

4. Barramento

São as “estradas” da placa-mãe: os caminhos por onde os dados viajam.

Todo computador tem quatro partes principais. A primeira é a memória principal: ela funciona como uma mesa de estudo, onde ficam os programas e os dados que o computador está usando naquele momento. A segunda é o processador, o cérebro do computador: ele segue as instruções dos programas e faz todas as contas. A terceira são os dispositivos de entrada e saída, que funcionam como portas: os dados entram pelo teclado ou pelo mouse e saem pelo monitor ou pela impressora. A quarta é o barramento, que são as estradas da placa-mãe por onde os dados viajam de uma parte para a outra. As luzes andando no barramento mostram os dados circulando. Fonte: Stallings (2017).

Passe por cada peça. A placa-mãe liga todos os componentes. O processador (CPU) executa as instruções dos programas. A memória RAM guarda os dados que estão sendo usados agora e perde tudo ao desligar (é volátil). O armazenamento (HD ou SSD) guarda os arquivos mesmo com o computador desligado. A placa de vídeo gera as imagens do monitor. A fonte transforma a energia da tomada e alimenta todas as peças.

Todo computador segue o ciclo entrada, processamento e saída. Exemplo: quando você aperta a letra A no teclado (entrada), o processador interpreta o sinal da tecla (processamento) e a letra aparece na tela (saída). Na animação, as luzes verdes são os dados saindo do teclado, passando pelo processador e chegando ao monitor. Além disso, os dados podem ser guardados no HD ou SSD (armazenamento) para serem usados depois.

O processador (CPU) é o “cérebro” do computador. A Unidade de Controle busca as instruções e organiza o trabalho. A Unidade Lógica e Aritmética faz as contas e as comparações. A memória RAM guarda os dados que estão sendo usados naquele momento. Esse ciclo de buscar, decodificar e executar instruções se repete bilhões de vezes por segundo. Na animação, as luzes correm pelas trilhas da placa-mãe até o processador, e os pentes de memória RAM piscam junto.

Os dispositivos de saída mostram o resultado para o usuário. O monitor exibe imagens, a impressora coloca o resultado no papel, as caixas de som e os fones reproduzem o áudio e o projetor amplia a imagem na parede. A impressora 3D vai além: ela cria objetos físicos a partir de um modelo digital. Na animação, as luzes saem do processador e chegam em cada dispositivo de saída.
